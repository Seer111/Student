# 第 13 页 · 挑战任务拆解

挑战任务看着大，拆开就四个点。后端两个：generateQuestion 加 type 参数，切换两套 Prompt；新增 gradeAnswer，接题目、要点、学生回答。

前端两个：按 question.type 渲染输入框，单选渲染 radio，简答渲染 textarea；提交时按类型分流，简答题走 /ai/grade-answer，不再在前端比较。

顺序建议：先做后端两个点，用 Postman 各跑一次；再改前端。否则前端调不通时，你分不清是后端没返回还是前端没解析。

验收很简单：同一个知识点，单选题和简答题各跑一遍，错题都进入复习列表。
