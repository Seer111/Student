## 0. 全局系统提示词（改任何一屏之前先贴这段）

```
你是这个产品的界面设计师。产品是「费曼学习平台」：知识点卡片 → 语音复述 → AI 评分 → 测评分题 →
知识图谱 / 3D 知识宇宙 / 3D 视界。用户是学生，每天打开，一屏里要能读到内容、看到自己的进度。

硬约束（不可违反）
1. 只改样式与渲染层：不动接口、数据结构、业务逻辑，不引入新依赖。
2. 全站只有一套色：中性面（白 / #f9fafb / #f2f4f7 的 tone step）+ 一个 ink（#1d1f20）+ 一组状态色。
   状态色只上「数据与状态」：未开始 #5b8ff9 / 学习中 #61a0a8 / 已掌握 #3ba272 / 待复习 #f6a609，
   必须与 2D 图谱、3D 宇宙、复述页、列表页完全一致。
   禁止再出现第二套主色（尤其 #007bff 这类默认蓝）、禁止把主色刷到导航/页头/按钮背景上做装饰。
3. 一屏最多一个实心主按钮；次操作 = 白底 + 1px 边框；破坏性操作默认低对比、放最右、聚焦时才显形。
4. 禁止：渐变（图表色带除外）、发光、毛玻璃、卡片静止态的大阴影、KPI 彩色圆图标、emoji、
   紫色/靛蓝当主色、全大写 + 字距的表头、斑马纹、左对齐的数字、假数据、每行一个彩色图标。
5. 数字：右对齐、等宽（tabular-nums）、固定小数位、千分位；真实的 0 写 0，缺失写灰色短横。
6. 字号五档封顶：页面标题 24px / 卡片标题 16px / 正文与表格 14px / 标签与轴 12px / 徽标 ≥11px。
7. 圆角二选一，不许中间态：紧 8/6/4px，或软 16/10/全圆。同层级卡片只用一个值；边框与阴影二选一。
8. 间距走 4px 基数：卡片间距 16、卡内 20、区块 24–48。
9. 动效只动 transform / opacity / box-shadow / background / color / border-color；
   统一 cubic-bezier(.22,.61,.36,1)，.14s / .2s / .34s；尊重 prefers-reduced-motion。
10. 可访问性：焦点可见（:focus-visible 2px 外框）、正文对比度 ≥ 4.5:1、图标按钮有 aria-label。

输出要求：先给「改动清单」（元素 → 改成什么 → 对应上面哪一条），再给代码；改完按验收清单自查。
```

## 1. 主页 · 我的知识点（150718.png）

```
【现状】白卡列表。卡片：12px 圆角、无边框、双层浅阴影、`kp-rise` 45ms 错峰入场；
        卡片头 = 标题 + 状态点 + 原生 select；正文是 `.markdown-content`（已去掉底色/描边/内边距，单层）；
        按钮四个：实心 #4f46e5「开始复述」、两个白底描边「开始测评」「编辑」、灰字低对比「删除」；
        正文限高不齐，卡片高度 212–844px；加载态是 3 张骨架卡。
【目标】一屏能扫完 11 个知识点：这是哪个知识点、我学到哪、下一步点哪。
【必须做】
1. 把「状态点 + 原生 select」合并成一个控件：胶囊按钮（淡底 + 同色深字 + 12px + 24px 高 + 6px 圆角），
   点开是同一套样式的下拉；状态点形状保留（空心/半实心/实心），颜色只做辅助。
2. 正文固定 4 行（-webkit-line-clamp）后接「展开」，整卡高度收敛到 200–280px 区间；代码块保留 220px 内部滚动。
3. 主按钮改成 ink（#1d1f20）实心，把 #4f46e5 让给「链接与焦点」；删除保持灰字、hover 才显形。
4. 列表顶部加一行 12px 灰字摘要：「11 个知识点 · 学习中 3 · 待复习 1」——统计是真的，不要做成 KPI 卡片。
5. 空态：一组 1px 虚线框 + 一句话 + 一个主操作，别只留一行「暂无知识点」。
【禁止】卡片再套一层灰底内容框、删除按钮红色实心、每张卡高度差 4 倍、状态用浏览器默认 select。
【量化验收】11 张卡同屏可见（1440×900）；卡片高度极差 ≤ 120px；全页只一处实心主按钮/卡；
            状态在灰度下仍可区分；390px 单列无横向滚动。
```

## 2. AI 助手（151646.png）

```
【现状】整页是一个 800px 宽、80vh 高、1px #ccc 边框、8px 圆角的外框，里面三段：
        头部（白底、1.2rem 标题 + 0.8rem #999 提示、1px #eee 下边框）；
        聊天区（#f9f9f9 底，气泡 20px 圆角，用户气泡 #007bff 白字、机器人气泡 #e9e9eb 黑字，
        最大宽度 70%，正文只 white-space: pre-wrap，不渲染 Markdown）；
        来源标签（#eef2ff 底 + #4a5fc1 字、10px 圆角）；底部输入条（白底 + 1px #ccc、
        输入框 20px 圆角、发送按钮 #007bff 20px 圆角、禁用 #a0cfff）。
【目标】看起来像「和你的知识库对话」，而不是一个蓝白 bootstrap 聊天框。
【必须做】
1. 配色归队：#007bff 全部移除。用户气泡用 ink 面（#1d1f20 底 + 白字）或淡中性（#eef1f6 + ink 字），
   机器人气泡 = 白底 + 1px #e5e7eb；主色只出现在「发送」按钮的焦点态与链接上。
2. 圆角归队：气泡 12px（与卡片一致，四角可只让「贴近说话人」那一侧略小），输入框 10px、
   发送按钮 8px；外壳去掉 1px #ccc + 8px 圆角的「框套框」，改成一张卡片（白底 + 1px #e8ecf3 + 12px）。
3. 正文渲染：机器人回答走 Markdown（复用 `MarkdownRenderer`），行高 1.7、字号 14px、代码块限高；
   不要继续 pre-wrap 纯文本。
4. 来源从「一排彩色小标签」改成回答末尾的「引用 3 条 · 展开」列表：序号 + 知识点标题（可点进详情），
   12px 灰字，不用彩色填充。
5. 空态与流式：初始态给 3 条真实示例问题（点一下填入）；生成中把三点动画换成
   「正在检索你的 11 个知识点…」+ 一条 2px 进度条；失败在气泡内给一句话 + 重试。
6. 布局：max-width 860px、高度 100% 自适应滚动区（不要 80vh 魔法值）；窄屏外壳去掉边框、满宽。
【禁止】第二个品牌蓝（#007bff）、气泡 20px 与卡片 12px 混用、彩色来源标签、彩色渐变气泡、
        两侧都加了「正在输入」以外的高饱和装饰。
【量化验收】全页数据/品牌色 ≤ 2 种；气泡与卡片圆角同属一套；回答内代码块有独立底色与 8px 圆角；
            键盘 Tab 顺序 = 输入框 → 发送；390px 无横向滚动。
```

## 3. 知识图谱（151653.png）

```
【现状】ECharts 力导向图：节点四色 = 状态（#5B8FF9 / #61A0A8 / #F6A609 / #3BA272），
        大小 = 20 + min(degree,6)*6；边 = 引用（#5b8ff9 1.8px 实线 + 箭头）/ 提及（#9aa9c4 1.2px 虚线）；
        图例已在批次 14 用显式 itemStyle 对齐 `CATEGORY_STYLE`；上方一行 `.graph-hint` 说明 + 统计
        「节点 N · 关系 M（引用 A · 提及 B）」；支持拖拽节点建立引用。
【目标】一眼读出「谁连谁、哪条边是我建的」，而不是一张烟花图。
【必须做】
1. 画布占满内容区、四周留 24px，背景与页面同一个 ground；不加网格、不加发光。
2. 节点：颜色只表示状态（四色上限）；label 12px 灰 #5f6368，密集时自动隐藏重叠；
   高亮态用 2px ink 外环，不用放大 + 发光。
3. 边：引用 1.5px 实线 + 箭头、提及 1.5px 虚线且透明度 ≤.5；两者不加阴影；
   悬停节点时把非邻接节点降到 30%。
4. 统计与图例合成一条工具条：左边「12 个知识点 · 9 条引用 · 1 条提及」，右边四个状态图例 + 两种边图例，
   12px、单行、可点筛选；不要上面一段解释、下面一段统计。
5. 拖拽建引用时给一条 1.5px 虚线跟随 + 目标节点高亮 + 松手前的一行提示「拖到目标知识点上建立引用」。
6. 空态：节点 ≤1 时给一句「先去添加第二个知识点，再回来建引用」。
【禁止】一个节点一个颜色、节点发光、密集网格背景、把统计做成 KPI 卡、图例与图上类型不一致。
【量化验收】数据色 ≤ 4；边 >30 条时仍能读出至少一条路径；图例项与图上出现的类型完全一致；
            拖拽一次建引用 ≤ 2 次点击；390px 下画布可缩放且不溢出。
```

## 4. 3D 知识宇宙（151659.png）

```
【现状】three.js 场景：星云穹顶 shader + 9000 点星场 + 程序化贴图星球（每颗 55ms 生成）+ 光晕 sprite
        + 两条航线层（引用亮实线 / 提及暗虚线）+ 飞船（引用=亮蓝大快 1.0/0.3、提及=暗灰小慢 0.6/0.13，
        InstancedMesh 锥体 + 机翼）+ 尾焰 Points + UnrealBloom(samples 4)；HUD 左下角堆了
        统计、两组图例、按钮和提示段；选中节点有浮层。
【目标】能「看结构」的宇宙：美是背景，结构是正文。
【必须做】
1. HUD 收成一个角、一块面板：统计用 12px 标签 + 14px 值（「12 颗星球 / 9 条航线」），
   图例最多两行（4 个状态 + 2 种边 + 2 种飞船），按钮 32px 高、半透明中性底 + 1px 亮边。
2. 星球颜色只表示状态；大小 = 关联数映射，口径与 2D 图一致（min(degree,6)）。
3. 航线：引用亮实线、提及暗虚线，线宽 ≤2px，不加额外发光层（交给 Bloom 统一处理）。
4. 飞船：颜色 + 体型 + 速度三个通道同时区分；尾焰颜色跟随航线；图例必须能解释「亮蓝大 = 引用」。
5. 浮层：白底 92% + 1px 边框（不用毛玻璃），标题 16px/600 + 一行 12px 状态 + 两行摘要 + 一个「进入详情」。
6. 降级：pixelRatio 封顶 2；prefers-reduced-motion 下停自转与飞船运动；首帧前给一张同尺寸占位。
【禁止】给每颗星球随机色、HUD 做成 KPI 卡片组、发光圆钮、毛玻璃面板、页面级渐变背景。
【量化验收】数据色 ≤4；图例能解释屏幕上每一种视觉元素；1440×900 首屏正文不被 HUD 遮挡；
            集显 40fps 以上；卸载后无残留渲染器/几何体。
```

## 5. 3D 视界 · Three.js 教学（151705.png）

```
【现状】`<h1 className="page-title">3D 视界</h1>` + 一段 `.graph-hint` 说明（含加粗小标题）；
        然后是 `.demo-panel`：三行 `.demo-row`——几何体 chips（立方体/球体/圆环结）、材质 chips
        （基础材质/标准材质）+ 颜色色块、开关行（5 个 checkbox + 一个 `btn btn-plain`「重置视角」）；
        再一行 `.demo-readout`（相机位置 / 物体旋转 / 帧率）；再是 `.demo-stage` 画布；
        最后 `.demo-notes` 7 条 `<li>`，每条含 `<b>` 标题 + `<code>` 代码片段。
        画布背景是深蓝 #1a2a3a，与浅色页面形成硬切。
【目标】像一个「实验台」：左边拨、右边看、下面读结论，而不是「控件堆 + 一堵文字墙」。
【必须做】
1. 版式改成两栏（≥1024px）：左侧 320px 控制台（白卡 + 1px 边框 + 12px 圆角），右侧画布撑满剩余宽度；
   窄屏上下堆叠。画布圆角与卡片一致，深色画布四周留 16px 内边距，避免「硬切」。
2. 控制台内部分组：几何体 / 材质 / 光照与辅助 / 视角，每组一行 12px 灰标题 + 控件；
   chips 用「白底 + 1px 边框，选中 = ink 底 + 白字」，不用高饱和填充。
3. 读数条 `.demo-readout` 改成 3 个等宽数据块（相机 / 旋转 / 帧率），数字等宽右对齐、12px 标签在上。
4. 7 条 notes 折叠成 4 条以内 + 每次交互只亮相关那一条（点「线框」高亮网格/材质的说明），
   正文 14px、行高 1.7、`<code>` 用 12px 等宽字 + 淡底 + 4px 圆角。
5. 「重置视角」从开关行里拎出来，放到画布右上角作浮层按钮（32px、半透明中性底）。
6. 光照开关关闭时给画布一层「视觉提示」文案（一行 12px 灰字），不要靠用户猜为什么黑。
【禁止】把 checkbox 排成一整行 6 个、notes 做成 7 条同级文字墙、画布用高饱和深蓝与页面硬切、
        控件用彩色填充表达选中。
【量化验收】≥1024px 两栏、<900px 单栏；控件区高度 ≤ 画布高度；notes 默认 ≤4 条可见；
            chips 选中态在灰度下仍可辨；帧率读数每 400ms 更新且不抖动布局。
```

## 6. 验收清单（改完逐条勾）

## 7. 五张图里最值得先改的三件事

1. **AI 助手整页是另一套设计语言**：`#007bff` 主蓝、`#e9e9eb` 气泡、20px 圆角、800px 硬宽、正文不渲染 Markdown。
   它和主页（12px 圆角、ink 主按钮、状态色体系）几乎没有任何共享变量——改它收益最大，且只动 `AgentPage.jsx` + `AgentPage.css`。
2. **3D 视界是「控件堆 + 文字墙」**：6 个控件挤一行、7 条 notes 平铺、画布与页面硬切。
   改成「左控制台 / 右画布 / 读数条」三段，教学效率与观感同时提升。
3. **主页卡片高度极差 4 倍（212–844px）**：这是列表无法扫读的根因，正文 clamp + 展开即可，
   顺带把删除按钮再降权一档。
